A swipe file built into Instagram.

Three things to know, then you're done reading this page forever.

  1. Hover a post or Reel in any grid, or open one, and click + Save to Research. It's saved immediately — no navigation, no sign-in.
  2. A small card appears right after saving — pick a collection and add a note if you want one. Both are optional; the save already happened.
  3. Click the toolbar icon to open your library: search, move between collections, and export everything as CSV, Markdown or JSON whenever you want.

Try it on Instagram →

No account. No cloud. No network.

Every saved post lives in this browser's local storage and is never uploaded — this extension makes no network requests at all, which you're welcome to verify in devtools. The flip side: your library is on this device only. Use Data → Export all data in the panel to keep a backup, and Import to bring it to another machine.

Why it only asks for access to Instagram

The save button and the numbers it captures only exist on instagram.com — this extension has no reason to run anywhere else, and doesn't ask to.

Tip: carousels save the first slide and note how many there are.
