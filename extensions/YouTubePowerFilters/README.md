# YouTube Power Filters

A Chrome Manifest V3 extension that adds advanced filters to YouTube search results, including views per day, channel size, duration, date, and outlier score.

## Development

```bash
npm install
npm run typecheck
npm run build
```

Load the generated `dist` directory as an unpacked extension in Chrome.

The implementation is cloned from YouTube Pro Filters and retains the same filtering behavior while using the YouTube Power Filters name in extension headers and user-facing surfaces.
