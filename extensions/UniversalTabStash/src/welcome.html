Universal Tab Stash

Save a set of tabs, close them, and get them back whenever you're ready.

1
Click the extension icon to open the panel, or press Alt+Shift+T.
2
Pick which tabs to stash (or leave them all selected), give the stash a name, and save.
3
Restore the whole stash — or one tab at a time — from the panel, whenever you need it.
No account, no sync, no server. Everything lives in this browser's local storage. Export everything as one JSON file any time from Data in the panel.
