# Cool Software Web Solutions — Chrome Extensions

Open-source Chrome (MV3) extensions built by Cool Software Web Solutions. Each
extension is a standalone project: no shared backend, no accounts, no
analytics leaving the device. Everything runs client-side against the page
you're already on.

## Extensions

Two are published; the rest are built but not yet submitted to the Web Store.
Each links to the PRD it was built against.

## How this repo works

```
.
├── LICENSE, NOTICE          Apache-2.0, applies to everything here
├── docs/extensions/         One PRD per extension — the product brief it was built to
└── extensions/
    ├── YouTubeSubcription/  Independent project: own package.json, src/, build
    └── YouTubeTranscription/  Same shape
```

- **Each extension is self-contained.** No shared code, no monorepo tooling —
  `cd` into an extension's folder and it builds on its own with plain `npm`
  scripts (esbuild, no framework). See that extension's README for exact
  commands.
- **`docs/extensions/`** holds the PRD each extension was scoped and built
  against — read one before a README if you want the "why" behind a design
  decision rather than the "what."
- **Build output is never committed.** `dist/` (the loadable unpacked
  extension), `release/` (the zipped Web Store upload), and generated
  `icons/` are all git-ignored and regenerated by each extension's build
  script. Web Store listing material (screenshots, promo video/images) lives
  outside this repo entirely — the Web Store keeps its own copy once
  uploaded.
- **Privacy posture is shared across both.** No backend, no OAuth, no
  tracking pixels. Where an extension talks to YouTube at all, it does so as
  a fetch from the browser using the session already signed into that tab —
  the same access the YouTube page itself has, nothing more.

## Building an extension

```bash
cd extensions/<name>
npm install
npm run build       # -> dist/, loadable via chrome://extensions → Load unpacked
npm run zip          # -> release/<name>-<version>.zip, for the Web Store
```

Requires Node 18+. Each extension's README documents its specific scripts,
permissions, and manual test checklist.
